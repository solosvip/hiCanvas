# hiCanvas

基于 [Cowart](https://github.com/zhongerxin/Cowart) 逐步建设的独立 AI 画板。

## 第一阶段

- 保留 Cowart 的基础画板体验，包括绘画、文字、图片、选择、批注和本地保存。
- 添加自定义生图模型配置，支持通过所选服务生成图片、根据参考图和批注改图。
- 复用并扩展 Cowart 的 MCP，让 Rex 中获得工具权限的 Agent 操作同一块画板。

画板内置文本模型和对话助手放到第二阶段。

## 当前状态

当前版本只建立仓库、工程规则和基础检查，尚未导入 Cowart 源码，也不能运行画板。后续导入上游代码时保留其许可证和来源记录，并分别核对第三方依赖的许可证。

界面以 Cowart 为参考。正式页面开工前，按项目规则完成设计令牌和公用组件确认。

## 环境与检查

使用 Node.js 24 和 Git。基础检查没有第三方依赖，不需要安装 npm 包。

```sh
npm run check
```

检查包含源码行数、文档位置、规则文件大小、CLI 规则入口，以及误入仓库的本地数据与密钥配置文件，同时运行这些检查的回归测试。提交前检查读取暂存区，GitHub CI 运行同一入口。

本机默认与当前提交比较；检查已提交的改动时用 `npm run check -- --base <基点提交>`。CI 自动使用 PR 的目标提交或本次推送前的提交。

首次克隆后启用本仓库的提交前检查：

```sh
git config core.hooksPath .githooks
```

目前没有应用构建命令；导入 Cowart 后补充启动、构建和功能测试说明。
