# 画板只经编辑命令修改；旧界面的整份快照提交保留到切换

所有修改画板的地方——MCP、批量生图、插入图片和网页、Agent 请求，以及以后的新编辑器——都改为提交编辑命令，由编辑层在 MIT 数据层的存储上执行：一批命令是一次事务，要么全部生效、要么全不生效；每条记录写入时就按数据模型校验；执行结果连同这次的变化一起返回。本机服务照旧先核对画板版本号再保存。现在的 tldraw 界面只会提交整份快照，所以它是唯一的例外，保留到换上新编辑器后删除。判定是否守住：阶段 3 结束时，服务端除旧界面的快照提交外，没有任何代码直接改快照里的记录。

## Considered Options

- 继续让各个入口直接改快照数据：每个入口各写一套规则，人和 AI 的修改结果会慢慢不一致，也无从记录谁改了什么、怎么撤销。
- 浏览器和服务之间立刻改为只同步命令：现在的界面做不到，等于先重写界面；放到阶段 4 新编辑器上线时自然完成。
