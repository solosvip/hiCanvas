# 幻灯片排版在编辑事务收尾执行，新旧界面共享纯计算

旧界面在操作结束后另排幻灯片，导致一次撤销不能恢复页位和框尺寸，复制页的旧归属提示也可能把副本拉回原框。决定由编辑层在正式事务收尾时，只查询此次受影响的 Slides 容器并完成排版；拖动预览不排版，撤销与重做精确恢复记录、不再整理。旧界面保留原触发时机，改用同一个纯计算入口，避免人、MCP 与旧界面采用不同几何规则。

作品页只包括直接子项中的图片和自有 HTML，按局部横向中心、父级 index 排序，留白与间距沿用旧参数转换；非空框可缩回但不小于 1048×600，空框保留尺寸。负参数可能导致裁切或重叠，作为旧格式兼容保留；间距负到会让页的先后顺序反转时，按刚好不反转的间距排，保证相邻中心至少差一个画布单位，存档参数原样保留。这是有意差异，避免每次收尾和旧计时器反复换序写入。非有限结果整笔拒绝。普通元素和组不拆成页，页自身旋转归零，容器及祖先旋转保留。

明确的父级选择优先于旧提示，自动收纳仅处理本次新建且没有明确父级的页，不扫描历史对象；整套复制保留树并映射已知提示。唯一选中 Slides 或其直接作品页时，粘贴根进入该 Slides，仍用原有落点策略；其他情况沿原策略。若排版必须修改锁定页或锁定容器，整笔拒绝并提供可区分原因码；不移动锁定页的追加允许执行。这有意取代旧版部分排版、父锁下删子页和复制树被拉回原框的行为，代价是删除锁页之前的页也可能被拒绝。
