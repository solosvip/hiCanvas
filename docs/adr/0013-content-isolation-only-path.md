# 生成网页只经内容宿主加载，来源权限只由两个受控入口授予

播放、截图、影片导出、网页编辑与幻灯片已完成实例消息通道迁移，删除开关和画板同源加载回退；生成网页只经 ADR0012 的随机实例来源加载，宿主不可用时明确失败。保留双路径会让相同作品因运行配置拥有不同的父窗口权限，也会让新入口意外退回父侧 DOM 操作，因此隔离成为唯一加载路径。

“脚本与同源不能同时开放”的边界是不能取得**画板来源**。实例保留自己的随机 HTTP 来源，用于模块和中性截图环境；改为 opaque 来源会重做 ADR0012 已验证的截图与握手方案。双权限只允许由两个指定构造入口产生：内容宿主先校验随机主机名、启动端口和父来源，再提供实例属性；外部嵌入仅给现有 HTTPS 服务白名单提供继承的权限。外部服务权限保持原样，属于受控边界。离线播放器继续使用 opaque 沙箱。

工程检查在工作区与暂存区同时禁止父页访问生成内容 DOM、srcdoc 回退及指定构造入口以外的来源权限授予。真实浏览器和合成资料桌面包分别验证实例、直接 HTML/SVG、重定向及画板被嵌入时拿不回画板身份；父接口的 Host、来源和客户端检查保持原有约束。检查约束代码入口，不证明任意混淆代码安全；运行门禁和浏览器自身的来源／框架策略共同守住边界。
