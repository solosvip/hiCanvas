# Gist 使用固定 ID 发布，不获得生成内容的控制通道

Gist 的官方嵌入脚本会在子页执行，仍按不可信脚本处理。复用 ADR0012 的每实例随机来源、配额和租约，但只接受经过校验的 Gist ID，由服务端生成固定包装；调用方不能提供 HTML、脚本地址或策略。若沿用生成网页登记，就会把编辑、播放、截图和消息通道能力无端交给第三方，因此 Gist 不经过素材准备器，不注入 bridge 或原文资源，不转交 MessagePort。

权限仍从 ADR0013 的内容宿主构造入口产生，Gist 只保留脚本与自己的实例来源；响应级 CSP 仅允许本 ID 的官方脚本、固定本地 bootstrap 哈希和官方静态 CSS，不开放表单、弹窗、顶层导航或下载。父接口的 Host、来源及客户端门禁独立保留；不能把子框自身导航请求的尝试说成零请求，验收以父接口接受数为零、父页身份和文档不变为准。

只显示整份 Gist，网址 query/hash 丢弃，暂不支持文件选择或指定版本。合成的固定官方响应可验证隔离与生命周期，不能证明真实 GitHub 脚本和样式的在线兼容；未知依赖应明确失败，不能为兼容自动扩大 CSP 或退回同源页面。
