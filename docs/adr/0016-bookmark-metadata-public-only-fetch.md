# 书签抓取只访问核对过的公网 IP，返回文字与修改画板分开

书签需要从用户给的网址补齐标题和描述；跟随任意网址或让代理自行解析，会把本机服务变成访问本机、内网和云元数据的代理。宿主只接受网址，拒绝特殊地址、混合 DNS、非默认端口和 HTTPS 降级；每一跳完整检查 A/AAAA 后只连接选定的数字 IP，在任何 HTTP 字节发出前核对对端、原域名的 TLS 证书和 SNI。连接不用共享 Agent、环境代理、登录凭据、来请求的身份或可配置的绕过开关。以后图片和图标抓取也必须沿用这个边界。

采用可取消的独立 Resolver 和直接连接，舍弃依赖系统代理、fake-ip、hosts 文件和部分系统 DNS 配置的兼容性；固定的特殊地址策略宁可拒绝少数可路由地址，也不把转换地址或特殊用途段当成普通公网。逐跳复核防止重绑定，绝对时限、有限并发、速率、头部和字节预算防止慢响应或无限内容占用宿主。只接受 identity HTML，不为兼容压缩或脚本生成的网页引入执行环境。

页面只经有界的头部扫描和字符集解码取得纯文字；xmldom 只用来解码转义过的短文本，页面、DOCTYPE、脚本和子资源不交给 DOM 执行或加载。canonical 只接受最终响应的同源网址，不再抓取。返回契约只有 title、description、url，不能返回 HTML 或把任意资源代理给内容页。

抓取接口不读写画板、设置或历史。后续自动补齐与手动刷新通过编辑层的语义命令写回，失败保留原网址卡片。把网络准备与画板事务分开，既能让界面、MCP 和后台复用相同服务，也能保持版本检查、取消和撤销各自的职责。
