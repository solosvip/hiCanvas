# Mac 桌面应用验证

范围：Electron 独立应用的启动、服务与 MCP 衔接；界面验证为重档，画板内部控件和样式沿用现有实现。

| AI 已验证 | 需要用户验证 |
| --- | --- |
| `npm run check`：72 项数据/API/协议及工程回归通过，生产资源和桌面运行代码完成独立打包。新增守卫覆盖本机深链、模型目录匹配、GUI 环境查找 REX、保存后切换及加载失败页退出；故意跳过边界/保存时见到红灯后恢复。 | 打开「应用程序」中的 hiCanvas，确认原有对话和模型符合预期。 |
| `npm run desktop:pack`：生成 arm64 Developer ID 签名应用与 ZIP，严格验证签名。`desktop:smoke` 直接通过应用自带 MCP 冷启动服务；读取16个工具、创建/重连对话、写画板、4张占位、AI断开后继续完成及2×2排版、HTML写回均有断言。只使用本机模拟API。 | 使用自己的模型生成一张图，确认真实服务兼容性、网络及生图质量。此轮未调用真实模型。 |
| macui 读回中文工具栏、设置、对话入口、1440×940和900×700窗口；检查原生窗口及设置截图，未见重叠、裁切或页面横向溢出。通过应用MCP实际唤起目标对话，CDP读回对话ID、文字、保存入口，确认页面没有Node/require权限。 | 拖动、绘画、粘贴、下载和长时间使用的手感由用户验收；此轮没有重新做完整影片/Slides导出验收。 |
| 实际关窗后健康接口仍存活；再次通过MCP打开保存的对话并读取原文字。切换对话时用标记确认执行了页面的现有保存入口。 | 从REX连接后在画板提交一次网页或影片请求，确认原Agent收到任务；自动回传的协议回归和GUI程序发现已测，真实Agent通知没有发送，避免打断会话。 |

界面证据保存在本工作区 `.scratch/desktop-check/`：`window.png`、`settings-narrow.png`。界面操作使用 macui，页面读数与MCP目标核对使用独立的 agent-browser CDP 会话，未操作用户浏览器。退出测试应用时驱动报告前台切回 Chrome，未为此使用前台键鼠命令。截图仅作为本轮走查证据，未建立像素对比守卫；启动、保存和协议边界已有自动守卫。

兼容限制：旧协议2服务没有返回设置目录标识时只能核对画板目录，需要保持连接配置中的设置目录与原服务一致。当前包是本机试用签名包，未公证、未提供自动更新。
