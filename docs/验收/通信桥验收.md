# Cowart 通用 MCP 通信桥验证

日期：2026-11-22。候选版本：v0.0.8。测试档：重，涉及后台生成与画板双向请求。

## 范围与环境

保留 Cowart 的图片、网页、影片、Slides 与标注工作流。图片接用户配置的 API；外部 Agent 经 MCP 制作和写回其他媒体；本轮没有增加内置文本助手。

使用 Node 24，统一入口 `npm run check`。测试资料、模型设置、模拟 API、私有 REX 服务及浏览器会话均与用户正在使用的画板隔离；素材为合成 HTML、文字和图片，不调用真实收费供应商。终端接收器是本地编译的合成程序，再由确定性模拟 Agent 使用真正 MCP 工具领取并写回。这验证了通信机制，不代表真实模型的理解与作品质量。

## 功能断言与用户验收

| AI 已自测及其保护的行为 | 需要用户验证的步骤与期望 |
| --- | --- |
| 整批 16 张先创建全部 4×4 占位；最多 3 个供应商请求并发；提交后切换默认模型仍使用原模型；供应商恰好调用 16 次 | 从 REX 一次要求多张独立图片 → 立即看见整批占位和动效，随后在原框显示结果、整齐换行 |
| 生成时移动/修改画板不丢数据；占位内新文字与背景保持坐标和层次；删除目标后只保留结果；单项失败不阻断其他项 | 生成期间移动一个框、删除另一个框 → 移动的结果留在新位置，删除的结果可在图片结果找回 |
| 重启仅恢复未发送队列；已发出的中断任务不自动重发；失败不自动重试 | 用自己的供应商核对尺寸、参考图/改图能力、耗时与错误提示 → 与其 API 能力一致；这是尚未调用的收费验证 |
| HTML/影片原位替换保留尺寸、旋转、父容器；Slides 页面有序归属于同一演示；跨对话请求和资源被拒绝 | 在自己常用的 REX Agent 中创建网页、影片、幻灯片 → 正确读取请求、按目标完成并回到同一对话 |
| 并发重复提交只通知一次；迟到回执不回退完成状态；更换接收进程后重发待办；不同 Agent 的领取互斥 | 退出并重连原 REX 对话 → 请求可继续，退出到 shell 时不得自动输入画板命令 |
| DOM 修改接口原位保存新内容及内容指纹；整套导出同目录，拒绝越界文件名 | 日常编辑与标注多轮迭代 → 原稿保留，新稿旁置，视觉与操作手感符合要求 |
| 63 项回归测试、样式/设计令牌/资源路径/工程边界及生产构建通过 | 正式生产使用前按既定计划解决 tldraw 许可；本轮保留官方许可提示 |

## 界面走查证据

使用自有 headless 浏览器会话，不接用户的 Chrome。原有画板风格和工具栏继承 Cowart，本轮只增加框内进度和统一通知。

- 网页：实际点击生成按钮，经独立 REX 终端通知、MCP 领取和写回；点击编辑文本，选中文本、键盘输入并保存，刷新后文字仍在；实际点击按标注修改，新稿出现在右侧，原稿文字保持不变。
- 图片：实际使用配置界面已有的模拟模型提交，观察原框加载动效、禁用重复提交以及结果替换。
- 影片：实际生成写回后检查播放控制与时间轴，点击导出影片；得到可读取视频元数据的 MP4，960×540、111025 字节，含音轨，浏览器读取时长约 1.067 秒（合成片长为 1 秒，编码含音频填充）。静音合成音轨先触发原版明确错误，换成合成有声音轨后导出成功。
- Slides：两页写回同一父框，实际演示翻页至 2/2；实际导出 HTML 得到两页与 Play.html，导出图片得到两张 PNG。
- 等待：没有绑定 Agent 的新对话提交请求，原框显示等待连接，通知说明请求已保存；刷新后仍存在。
- 布局：1440×1000 与 390×844；窄窗口生成面板左右为 16/374，底边约 737，工具栏顶边 788，二者不重叠；深色画板的进度文字发现偏暗，已改为跟随 tldraw 主题文字令牌；高缩放生成面板曾被底部工具栏遮挡，已统一预留工具栏空间。

截图和日志仅保存在本机忽略目录 `.scratch/verify-bridge/`。走查看过实际截图与界面；通信、排版、并发和保存有持续回归测试。浏览器按钮与像素走查未接入持续 CI 守卫，无法声称未来的外观变化会自动拦截。

## Standards

规范审查关闭了重复投递、迟到回执、测试默认恢复真实资料库的缺陷。测试必须显式提供隔离 workspace，构造生图队列前有硬性守卫；轮询只读状态摘要，不重写请求文件或回传图片附件。收口复查无新增可确认 P1/P2 阻断项。

## Spec

需求审查关闭了占位替换删除用户子形状、图层遮挡、Gemini 非法比例和重连接收进程未获通知的缺陷。后续发现大小写索引排序不一致，改用 tldraw sortByIndex，新增用例先失败后通过。DOM 编辑走查发现返回缺少内容指纹，补上接口契约断言并修正。已对图层、并发通知和比例分别注入错误，确认回归测试变红后还原。

自动唤起适配已验证 REX 的本机终端 API。其他 MCP 宿主可以主动操作与领取请求，自动唤起仍需相应宿主通知接口；不能把 MCP 协议等同于任意宿主都支持主动开启对话。
